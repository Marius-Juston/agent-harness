# Research notes

One note per topic, in house style: `uv run dev research new <slug> --title "..."` creates one. The index of all
notes, `INDEX.md` here, is generated by `uv run dev docs`; read it before starting new research.

Every note carries a `Search coverage:` line near the top, beside `Status:` and `Labels:`: the worst `discovery`
line `uv run dev lit search` printed (sources up, any down, the date). `uv run dev check` fails a note without it.
A search that reports DEGRADED exits 1: stop, and start the round again only once `dev lit status` reports OK.
