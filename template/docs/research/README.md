# Research notes

One note per topic, in house style: `uv run dev research new <slug> --title "..."` creates one. The index of all
notes, `INDEX.md` here, is generated by `uv run dev docs`; read it before starting new research.

Every note carries a `Search coverage:` line near the top, beside `Status:` and `Labels:`: the literature sources
`uv run dev lit status` showed up when the searches ran, any that were down, and the date. `uv run dev check` fails a
note without it. Do not start a research round while `dev lit status` reports DEGRADED.
